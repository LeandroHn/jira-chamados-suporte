# Central de Chamados de Suporte — Jira

**Projeto | Área: QA / Help Desk**

## Sobre o projeto

Projeto simulado no Jira reunindo chamados de suporte técnico variados —
bugs, solicitações de serviço e dúvidas de usuário — com prioridade,
status e descrição estruturada, demonstrando uso prático da ferramenta de
ticket mais pedida em vagas de QA e Help Desk júnior.

## Estrutura do projeto

**Tipos de ticket:**
- 🐞 Bug — falha técnica no sistema
- 📩 Solicitação de Serviço — pedido de acesso, instalação, criação de usuário
- ❓ Dúvida — pergunta de usuário sem defeito técnico

**Workflow:**
Aberto → Em Andamento → Aguardando Resposta do Usuário → Resolvido → Fechado

**Prioridades:** Crítica, Alta, Média, Baixa

## Padrão de descrição usado

Cada ticket segue uma estrutura fixa, dependendo do tipo:
- **Bug:** ambiente, o que foi feito, o que aconteceu, o que era esperado
- **Solicitação:** solicitante, o que precisa, justificativa
- **Dúvida:** contexto, pergunta

Tickets resolvidos incluem comentário documentando a causa raiz e a
solução aplicada — não só o encerramento do chamado.

## Habilidades demonstradas

- Configuração de projeto e workflow no Jira
- Categorização correta por tipo e prioridade de chamado
- Escrita de descrição técnica clara e reprodutível
- Documentação do ciclo completo de um chamado (abertura → resolução)
